Projects

  • Rust · Candle

    Gemma 4 Inference Engine

    A from-scratch inference engine for Gemma 4 E4B: I wrote the model logic (attention, RoPE, per-layer embeddings, KV cache, sampling) on top of Candle's Q8_0 kernels. It also implements GCG, a gradient-guided search for adversarial prompt suffixes, with a custom backward pass through the quantized layers.

  • Go · Protobuf

    Retina — Distributed Internet Measurement Platform

    An open-source system that continuously maps Internet routes from vantage points around the world, over IPv4 and IPv6. A generator produces probing directives, the orchestrator schedules them to agents over Protobuf on TCP, and an API streams the results live to any number of subscribers. I co-designed the system and built its adaptive-rate scheduler, which paces millions of probes.

  • Go · ClickHouse

    MPAT — Measurement Platform Analysis Tool

    The analysis pipeline behind our Forwarding Score metric (IMC ’25), which rates the quality of Internet route surveys. It processes 45+ billion rows of traceroute data from several measurement platforms in under 6 hours.

  • Python · PyTorch

    AI Text Detector

    Implements and compares four methods for detecting AI-generated text side by side: two zero-shot methods from recent papers, Binoculars and Fast-DetectGPT, a DeBERTa classifier, and GLTR, with an explanation of each verdict.

  • Python · PyTorch

    Multi-Person 3D Pose Estimation

    A depth-aware pipeline estimating 3D poses of multiple people from a single image, built on RootNet and evaluated on the COCO, CrowdPose and LSP benchmarks.

  • Go

    garagat

    A pure-Go port of the C++ traceroute engines caracal and caracat: a stateless IPv4/IPv6 Paris traceroute and ping engine with no cgo or libpcap, using raw sockets and kernel BPF filters generated in Go.

  • Go · CRIU

    Kubernetes Live Pod Migration

    A Kubernetes controller that live-migrates running containers between nodes using CRIU checkpoint/restore, preserving their state.
